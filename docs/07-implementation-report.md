## 1. 追加规则

- 每完成一个 Step（05 §6）追加一段；不修改已写段落。
- 每段含：范围 / 对照步骤与任务 / 完成项（引用 ACC）/ 变更与偏差 / 触发风险 / 遗留 / 下一步。
- 结论三态：✅ 完成 / ⚠️ 部分（列遗留）/ ❌ 阻塞（写原因与需要的输入）。
